## はじめに
### Crackmes.oneとは
Crackmeとは、リバースエンジニアリングの技術を練習するために作られたプログラムのことです。一般的なCrackmeには、パスワードやシリアルキーの入力を求める認証処理が組み込まれています。例えば、実行すると次のように表示されます。
```
Enter password: ********
Wrong password!
```
解析者はソースコードを見ずに、実行ファイルを解析して正しいパスワードや認証アルゴリズムを特定します。  
[Crackmes.one](https://crackmes.one/)とは、CrackmeをダウンロードできるWebサイトです。

## 問題
今回は難易度2の[kamil123's Needle in a Haystack](https://crackmes.one/crackme/6aba3db8ca34abba98f82dd0)を解きます。ダウンロードして展開します。実行してみると
![](/images/needle/console.png)

パスワード入力ができます。間違ったパスワードを入力すると"Wrong Password: Try again"と表示されます。また、先頭に大事なことが書いてあります。
```
=================================================
   Crackme - Needle in a Haystack (Very Easy)
   One of the strings inside this program is
   the real password. Everything is visible.
=================================================
```
正解パスワードはこのプログラムの中に保存されているらしいです。

## 解法
### 事前準備
Detect It Easy (DIE) で実行ファイルの情報を取ります。
![](/images/needle/DIE.png)

パッキングされていません。なので、静的解析していきます。

### 動的解析
比較時の`uVar4`の値を調べます。x64dbgを起動し、実行ファイルを開きます。そして、文字列検索で`Try again`を検索し、該当箇所周辺を見ます。
![](/images/needle/breakpoint.png)

```
cmp ebx,edx
je needl.7FF66D138E08
```
から`ebx`、`edx`が`uVar4`、`uVar9`に対応していることが分かります。ではここにブレークポイントを置いて実行しましょう。上図のように`ebx`レジスタには`0x2DE0A74A`が、`edx`レジスタには`0x9BBB04BC`が入っています。ということは、上の命令とかを鑑みて、最終比較時の`uVar4`には`0x2DE0A74A`が入ることが分かりました！

### まとめ
Ghidraを使用して逆コンパイル結果をたどっていきました。比較部分から何をしているかを追っていき、それを基にハッシュ値変換コードを作成しました。また、プログラム内の文字列一覧から、正解文字列候補を調べました。x64dbgで得た、比較用の値と正解文字列候補を変換したハッシュ値を比較することで、正解文字列を取得しました。
